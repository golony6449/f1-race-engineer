# 서킷 지식 베이스 (kb)

추월·코칭 무전이 "서킷 레이아웃을 알고" 말하도록 모은 서킷별 기반 정보다. 코드가 읽는 데이터 파일이 아니라 사람·에이전트가 읽고 규칙·문장 틀을 만들 때 쓰는 문서다.

- 코드가 읽는 코너 구간·중심선은 `src/f1re/tracks/data/*.json`에 있다. 이 kb의 랩 거리(m)는 모두 그 파일 기준이다.
- 기준 규정은 **F1 25 = 2025 시즌**이다. 다른 시즌 정보는 따로 표시한다.
- 확신도 표기: **높음**(공식·여러 출처 일치), **중간**(출처 하나·해석·시대 차이), **낮음**(게임 가이드·추정). 낮음 항목은 무전 규칙에 바로 쓰지 말고 게임 텔레메트리로 먼저 확인한다.

## 새 서킷 추가

`circuits/<서킷>.md`를 스즈카 문서와 같은 절 구성(요약 → 랩 거리 지도 → 추월 지점 → 셋업 연결 → DRS → 방어 → 위험 구간 → 무전 타이밍 → 전략 맥락 → 확인 필요 → 출처)으로 만들고 위 표에 한 줄 추가한다.
