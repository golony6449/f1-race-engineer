F1 레이스 엔지니어 무전

게임 PC에서 이 페이지를 띄워 두면 레이스 엔지니어 무전이 헤드셋으로 나옵니다. 화면(차량 상태·지도)은 태블릿으로 보세요.

무전 연결 대기
음성: 음성 오프라인

마지막 무전

아직 무전이 없습니다.

백그라운드 탭이 잠들지 않게 하기

  • Chrome·Edge에서 이 탭을 고정(pin)하고, 설정 → 성능의 "이 탭을 항상 활성 상태로 유지"에 이 사이트를 등록하세요.
  • 사이트 설정의 소리 권한을 허용으로 두고, Windows 전원 설정에서 화면 끄기·절전으로 인한 네트워크 절전을 해제하세요.
  • 연결이 끊기면 이 페이지가 1초마다 다시 연결합니다. 브라우저를 새로 열면 무전 연결 버튼을 한 번 다시 누르세요.
